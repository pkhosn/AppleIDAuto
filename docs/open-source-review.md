# 开源副本检查记录

本记录仅包含清理类别、文件位置和验证结论，不包含真实配置值或敏感样本。本记录描述初始脱敏交付阶段的检查结果。后续经授权的发布目标为 https://github.com/wupingan/AppleIDAuto，发布使用独立初始提交，不引入原项目历史。

## 文件与清理

- 输入为当前工作区的 331 个 Git 跟踪文件，按审核清单复制 296 个文件，另添加本记录。
- 排除 32 个旧前端构建文件、2 个固定测试密钥文件，以及 1 张含账号界面的旧教程截图；同时移除截图引用。
- 真实环境配置、运行目录、日志、数据库文件、缓存、浏览器资料、证书、备份和依赖目录均未复制。
- 原站点或部署引用、交流群、历史仓库链接及固定支付网关已清理。发布前将仓库地址统一更新为用户明确指定的公开发布目标；部署域名继续使用通用占位地址。
- 保留通用配置模板、数据库结构及非敏感初始化值。支付默认关闭，网关、商户号及密钥为空；缺少网关时三个支付入口均拒绝发起支付。
- 邮件签名测试使用 OpenSSL 在内存中生成临时密钥，类清理时释放引用，源码不保存密钥文件。
- 弹窗库移除了按域名触发的远程音频请求和页面交互禁用逻辑，保留弹窗实现、原许可与修改说明。
- 上游版权、许可证和依赖来源保留；前端通用图形和图标经人工查看。部署需自行安装依赖、生成配置并构建前端。

## 验证结果

所有构建和运行测试均在独立临时副本中进行；开源目录没有加入依赖、构建产物或测试输出。

- 全量文件清单核对通过；生产配置中 9 个非通用值逐一比对，未发现副本残留。
- 原站点及部署标识、常见凭据格式、私钥内容扫描未发现确认的问题。
- detect-secrets 使用本地扫描并关闭凭据联网验证，34 个候选项经逐项检查，均为测试假数据、占位符或代码字段误报；未保存包含真实值的扫描样本。
- 22 个敏感或生成路径的忽略规则检查通过；8 个必需源码与模板路径仍可纳入 Git。
- 98 个 PHP 文件语法检查、升级脚本 Bash 语法检查，以及修改后的弹窗库 JavaScript 语法检查通过。
- 支付默认配置、未配置密钥的验签拒绝、三个支付入口的空网关拒绝检查通过，使用桩对象验证，没有数据库连接。
- 邮件签名测试 4 项通过，包含无签名、错误域名、篡改与 DNS 失败场景。
- 前端 37 项测试通过；正式版前端构建成功。
- 后端根测试目录的 74 项回归用例已分批验证通过：初次 67 项通过，补齐隔离环境中的 PHP 依赖后 6 项通过；另 1 项改为读取示例配置后通过。正式版产物检查使用临时副本中新构建的文件完成。
- 数据库 SQL 仅保留空配置、关闭的功能默认值以及结构迁移；没有导入或导出生产业务库。
- 原项目的全部跟踪文件与两份真实环境配置均通过前后 SHA-256 比较，内容未变。
- 初始脱敏交付时，目标 Git 分支为 `main`，提交数、暂存文件数和远程地址数均为 0；没有复制原项目 Git 历史。后续发布仅包含脱敏源码的独立初始提交，使用 GitHub noreply 邮箱，不包含私人邮箱。

## 使用前需完成

使用自己的 fork 时，将文档中的 GitHub 仓库地址替换为自己的地址。按部署指南配置自己的密钥、域名和服务，安装依赖并构建前端。此次未使用真实账号、在线支付、生产数据库或线上站点进行端到端测试；这些行为需在自己的隔离环境中另行验证。
