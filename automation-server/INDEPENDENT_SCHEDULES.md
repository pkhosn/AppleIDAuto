# 五项独立自动化周期

公共部署、密钥和恢复配置分别见[部署指南](../docs/deployment.md)、[配置指南](../docs/configuration.md)。本页是周期规则的权威说明。

## 开关与配置

独立调度由 MySQL `site_config` 中的 `automation_independent_enabled` 发布开关控制；未配置时默认关闭。关闭时保留配置，继续使用兼容的统一周期逻辑，不等于禁用账号。全局周期保存不会自动打开发布开关。

在后台“品牌与站点”设置全局默认周期（分钟）。账号编辑页可以沿用全局设置，也可以自定义周期或逐项选择周期来源。每项可设为 1–43200 的整数分钟。切换显示单位只会换算显示值，不会改变实际时长。

| 功能 | 配置键 | 默认分钟 |
| --- | --- | --- |
| 双重认证检测与邮件安全设置回滚 | `two_factor` | 30 |
| 密码检查 | `password_check` | 30 |
| 资料恢复 | `profile_restore` | 360 |
| 设备清理 | `device_cleanup` | 30 |
| 定期改密 | `password_update` | 1440 |

`account.automation_schedule` 保存 v4 JSON：`version=4`、`mode=global/custom/mixed`、每项 `features` 的 `source` 和 `minutes`，以及 `shared={enabled, minutes, features}`。共用周期开启时，只覆盖所选功能的有效周期，不会开启这些功能；关闭后恢复各自周期并保留成员和数值。

新账号默认跟随全局周期，系统仍可读取旧配置。旧版四项配置扩展为五项后，不会因此自动启用设备清理。每项功能仍受对应账号开关和总开关 `enable` 控制；账号冻结后，所有自动调度都会停止，即使定期改密标志仍然开启。

双重认证回滚还需账号启用对应邮件恢复方式、配置救援邮箱，并取得通过验签的有效 Apple 安全设置恢复邮件。资料恢复以账号编辑页保存的目标姓名、出生日期、国家/地区和语言为基线。

## 调度与恢复

- 调度器约每 30 秒同步一次配置，并在执行前重新读取账号状态。执行修改前还会再次请求授权。
- 只合并已到期功能。未来任务保留原时间，不再提前合并临近到期项。
- 下次正常执行时间从本次任务结束时起算。时间上可能附加确定性抖动：不超过 `SCHEDULE_JITTER_SECONDS`（示例为 180 秒），也不超过周期的 10%。页面显示计划时间，不代表任务一定会在该时刻执行。
- 关闭某项取消其后续计划；保存普通资料只同步配置，首次启用或已到期项仍可入队。“运行到期项”也受授权与待核验保护。
- 所有账号共享驱动并发限制。`WORKFLOW_V2_ENABLED=false` 时不启用复合工作流；开启灰度后，适用任务可按检查、资料恢复、设备清理、改密顺序复用会话，改密最后执行。
- 修改前技术故障按 `TECHNICAL_RETRY_DELAYS`（示例 30、120、300 秒）有界退避；排队与执行分别计时。
- 邮件密码恢复和安全设置回滚均可能改密，成功后重置改密周期，避免本轮再次定期改密。
- 已提交且未确认的修改标记为 `uncertain`，冷却后仅做只读核验；设备清理、资料保存、改密不会自动重放。仍不能确定时等待人工处理。
- 改密候选凭据先保存在受限的 `scheduled-password-escrow` 目录，主站回写并读取确认一致后删除；回写失败只恢复回写，不再次访问 Apple。

SQLite 的 `feature_schedule` 保存功能状态和下次时间，`task_runs/task_run_steps` 保存阶段、心跳、步骤及核验决策；MySQL 保存账号配置。备份和回退必须同时考虑两侧状态，见[运维指南](../docs/operations.md)。

## 切换独立调度

先备份并部署兼容的 PHP、前端、调度和驱动，确认没有运行中或待核验任务。以下为运维命令，会访问实际配置的管理站与数据库；不在测试或文档检查中运行：

```bash
php tests/switch_independent_schedules.php status
php tests/switch_independent_schedules.php on
# 必要时切回兼容的统一周期逻辑
php tests/switch_independent_schedules.php off
```

脚本检查调度兼容性，遇到运行中或 `uncertain` 结果会拒绝切换。切换不改变账号启用状态，正常在 60 秒内同步。不要通过恢复旧数据库来覆盖已成功修改的密码；历史库结构迁移另见运维指南。

验证命令及隔离数据库要求集中在[开发指南](../docs/development.md)。浏览器周期测试使用虚构账号并拦截业务 API，不需要真实 Apple 修改。
